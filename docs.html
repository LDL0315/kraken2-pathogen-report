工具概述（方法引用）

method
本研究采用一款基于浏览器的本地化病原体筛查工具对 Kraken2 分类结果进行判读。该工具读取 .k2report 报告文件，通过内置的《人间传染病名录》病原体知识库（500 条目）对每个分类单元进行注释。知识库采用两级匹配策略：种级及以下条目（species/subspecies/isolate/biotype）执行精确 TaxID 匹配；属级及以上条目（genus/family/species group）执行分支级匹配，即该分类下所有子代物种均视为潜在病原体检出。工具综合知识库命中、危害程度、reads 分布、分类层级和 minimizer 信息计算证据分，并将结果分为"重点关注""需复核""低丰度线索""背景/暂不报告"四个等级。全部数据处理在浏览器本地完成，无需上传至服务器，可输出交互式 HTML 报告、多样本比较矩阵及 CSV 汇总表。

使用说明

local only
文件输入：上传 Kraken2 `.k2report` 文件，支持标准 6 列 report，也支持 `--report-minimizer-data` 生成的 8 列 report。
单样本报告：用于查看一个样本的自动摘要、重点病原体检出表、域级组成和原始分类树检索。
多样本比较：用于比较多个样本中同一病原体线索的检出状态和指标，可导出 HTML 或 CSV 矩阵。
本地处理：所有解析、筛选和报告导出都在浏览器本地完成，样本文件不会上传到服务器。
复核建议：正式报告前建议结合阴性/空白对照、覆盖度、基因组分布、近缘物种误分配和必要的复核实验。

判读标准

rule based
总体原则：本软件基于 Kraken2 `.k2report` 文件整理病原体筛查结果。软件不会把所有物种注释都作为病原体报告，而是先根据病原体知识库和补充规则筛选候选项，再结合 reads、分类层级、minimizer 信息和样本背景进行分级展示。
候选范围：进入“重点病原体检出”表的 taxon 需要满足以下条件之一：TaxID 命中内置病原体知识库或用户自定义病原体库；或名称命中补充病原体规则，例如部分细菌、病毒、真菌、原虫或寄生虫相关属名/关键词。
降噪规则：人源序列、合成序列、未培养或环境来源条目、非特异性分类节点、与样本类型不匹配的常见共生菌或背景菌、direct reads 极低的低丰度命中，通常会被降低优先级或归为背景/暂不报告。
证据分：每个候选病原体会计算 0-100 的证据分。证据分用于结果排序和复核优先级判断，不代表阳性概率，也不等同于临床确诊置信度。
证据来源：证据分主要参考知识库命中、知识库风险等级或危害程度、是否注释到明确 species/subspecies、clade reads、direct reads、distinct minimizers、疑似背景/污染/非特异性命中，以及当前选择的样本类型。
重点关注：表示该 taxon 为病原体知识库中的高关注对象，或具有较强的 reads/minimizer 支持。此类结果建议优先结合覆盖度、阴性/空白对照、近缘物种分布和必要的复核实验进一步确认。
需复核：表示该 taxon 具有明确病原体线索，但证据强度、风险等级、reads 数量、minimizer 分布或样本背景尚不足以直接列为重点关注。此类结果建议结合原始 reads、覆盖分布和对照样本判断。
低丰度线索：表示该 taxon 命中数量较低，或可能属于条件致病、共生、背景或低水平污染来源。此类结果通常作为筛查提示，不建议单独作为阳性结论。
背景/暂不报告：表示该 taxon 证据不足，或更可能来源于人源、合成序列、环境/未培养条目、非特异性分类或背景污染。默认情况下此类结果可被隐藏。
父级去重：如果已经检出明确的 species 或 subspecies，软件会隐藏其上级 genus/family 命中，避免同一来源在报告中重复出现。
展示排序：寄生虫/原虫和寄生虫/蠕虫优先展示，病毒其次，细菌再次；同一类型内按证据分从高到低排序，证据分相同时按 direct reads 从高到低排序。

重点病原体检出列说明

columns
判读软件给出的复核优先级，包括重点关注、需复核、低丰度线索、背景/暂不报告。该字段用于提示后续复核顺序，不代表临床确诊结论。
病原体Kraken2 注释到的 taxon 名称。若该 TaxID 命中病原体知识库，会同时显示中文名；下方备注可能包含 TaxID、危害程度、BSL 等级、相关疾病、传播途径和建议样本类型等信息。
类型病原体类别，来自知识库或补充规则，例如细菌、病毒、真菌、寄生虫/原虫、寄生虫/蠕虫、待分类。该字段也会影响展示排序。
证据分软件内部计算的 0-100 分值，用于衡量该 taxon 的复核优先级。分值综合知识库命中、风险等级、clade reads、direct reads、分类层级、minimizer 数量和背景扣分等因素。证据分不是阳性概率，也不是临床置信度百分比。
clade%Kraken2 report 中该 taxon 及其所有子节点 reads 占总 reads 的比例。它是树状累计比例，例如某个 genus 的 clade% 包含其下所有 species 的 reads。
clade reads分配到该 taxon 及其所有子节点的 reads 数。该值适合观察某个分类分支的总体信号，但不能单独说明 reads 都明确属于该 taxon 本身。
direct reads直接分配到该 taxon 本身的 reads 数。相比 clade reads，该值更适合判断该 taxon 是否有明确命中；对于病原体筛查，direct reads 通常是更重要的证据之一。
minimizers仅在 Kraken2 report 使用 `--report-minimizer-data` 时显示，格式为 distinct minimizers / total minimizers。distinct minimizers 表示不同 minimizer 的数量，total minimizers 表示 minimizer 命中的总次数。distinct 越多通常说明证据分布越丰富；total 较高但 distinct 很少时，需要谨慎解读。

Kraken2 推荐命令

backend
推荐输出：本软件读取 Kraken2 `.k2report` 文件。建议在 Kraken2 分析时输出标准 report，并开启 minimizer 信息。

双端测序

kraken2 \
  --db /path/to/kraken2_db \
  --threads 24 \
  --paired \
  --gzip-compressed \
  --confidence 0.05 \
  --minimum-hit-groups 3 \
  --report sample.k2report \
  --report-minimizer-data \
  --output sample.kraken \
  sample_R1.fq.gz sample_R2.fq.gz

单端测序

kraken2 \
  --db /path/to/kraken2_db \
  --threads 24 \
  --gzip-compressed \
  --confidence 0.05 \
  --minimum-hit-groups 3 \
  --report sample.k2report \
  --report-minimizer-data \
  --output sample.kraken \
  sample.fq.gz

临床样本建议先去宿主

bowtie2 \
  -x /path/to/GRCh38_index \
  -1 sample_R1.fq.gz \
  -2 sample_R2.fq.gz \
  --very-sensitive \
  -p 16 \
  --un-conc-gz sample.nonhuman_R%.fq.gz \
  -S /dev/null
kraken2 \
  --db /path/to/kraken2_db \
  --threads 24 \
  --paired \
  --gzip-compressed \
  --confidence 0.05 \
  --minimum-hit-groups 3 \
  --report sample.k2report \
  --report-minimizer-data \
  --output sample.kraken \
  sample.nonhuman_R1.fq.gz sample.nonhuman_R2.fq.gz
参数建议：`--report` 生成本软件读取的核心文件；`--report-minimizer-data` 输出 distinct/total minimizers；`--confidence 0.05` 适合初筛，较保守场景可尝试 0.1；`--minimum-hit-groups 3` 可减少单个局部匹配造成的误报；`--output` 保留逐 read 分类结果，便于后续 reads 提取和覆盖度复核。
数据库建议：常规病原体筛查建议优先考虑 Kraken2 PlusPF；需要更广谱补充时可使用 core_nt。完整 nt 覆盖广，但冗余和背景命中更多、运行成本更高，不建议作为默认生产筛查库。
结果保存：后端建议至少保存 `sample.k2report`、`sample.kraken`、`sample.log` 和 `sample.run.json`。`sample.run.json` 可记录数据库路径、Kraken2 版本、confidence、minimum-hit-groups、是否开启 minimizer 数据、宿主去除方式和单双端模式。

判读数据库覆盖

打开病原体条目
内置来源：当前基础库由《人间传染病名录》生成，包含 500 个病原体条目。
匹配层级：species/subspecies/isolate/biotype 级别为精准匹配（仅该 TaxID）；genus/family/species group 级别为 clade 全分支匹配（该分类下所有子孙 species 均视为病原体检出）。
可维护页面：病原体条目已独立为管理页，可搜索、编辑、新增、上传 CSV/JSON 合并，并下载当前知识库。
判读生效方式：在管理页保存到本地的修改会自动参与主报告判读；若更换浏览器或电脑，可先下载 JSON/CSV，再在新环境上传导入。

说明：当前覆盖范围是本工具内置的初筛规则，不等同于完整临床病原体知识库。后续可替换为正式 pathogen taxid 知识库。
