# Kraken2 病原体检测报告网页

这是一个纯前端静态网页工具，用于读取 Kraken2 `.k2report` 文件并生成病原体检测报告风格的可视化结果。

## 使用

直接用浏览器打开 `index.html`，或在当前目录启动一个本地静态服务：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

- 支持 Kraken2 标准 6 列 report。
- 支持 `--report-minimizer-data` 产生的 8 列 report。
- 单样本报告：自动摘要、重点病原体表、证据排行、域级组成、原始分类树检索。
- 多样本比较：样本检出概览、病原体检出矩阵。
- 单样本报告可导出为独立 HTML 文件。
- 多样本比较可导出为独立 HTML 文件，病原体矩阵可导出为 CSV 文件。
- `docs.html` 提供使用说明、判读标准、列说明、Kraken2 推荐命令和判读数据库入口。
- `pathogen-db.js` 由《人间传染病名录》xlsx 生成，当前内置 500 个病原体条目（含 112 个 genus/family 级 clade 分支匹配 + 388 个 species 级精准匹配）。
- `database.html` 提供病原体条目管理，支持搜索、编辑、新增、CSV/JSON 上传合并、CSV/JSON 下载，并将修改保存到浏览器本地。
- 所有解析均在浏览器本地完成，不上传样本数据。

## 判读边界

本工具基于 Kraken2/nt report 做规则分层和可视化，输出的是“检测线索”和“复核优先级”，不是临床确诊结论。正式报告应结合样本类型、阴性/空白对照、覆盖度、基因组分布、近缘物种误分配和必要的复核实验。
